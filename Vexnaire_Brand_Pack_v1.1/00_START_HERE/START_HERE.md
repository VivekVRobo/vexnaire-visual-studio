This folder contains the approved Vexnaire Visual Studio brand system.

- `01_MASTER_LOGO/Premium_Render/vexnaire-master-premium.png`

## Brand colors
- Obsidian: `#0A0A0A`
- Ivory: `#F4F0E8`
- Stone: `#B9B2A7`
- Violet: `#C9A6FF`

## Typography
- Display / editorial: Playfair Display
- Headings / UI / wordmark support: Manrope
- Body copy: DM Sans

## Important
The premium 3D symbol is a presentation expression. For small sizes, favicon use, print marks, watermarks, and most interface use, prefer the flat vector symbol.

The wordmark guideline board is the approved visual reference. The included SVG wordmark/lockups are web-ready implementations built with Manrope and should be used consistently on the current website unless a custom-lettered vector wordmark is commissioned later.
