# Vexnaire Visual Studio

A standalone multi-page website for Vexnaire Visual Studio, an independent visual design studio led by Vivek Vala. The commercial front door is advanced technology, mobility and premium product imagery, with broader capability across entertainment, architecture, publishing and other visual disciplines.

## Current capability

- 51 curated showcase pieces with web previews across 8 commercial disciplines.
- 4K is the standard final-delivery option for a commissioned project.
- 8K and 16K delivery are available only when the project use case, source artwork, and technical review support them. They must be stated in the written project scope.
- A master means the final approved export at the resolution, file format, crop ratios, and usage rights agreed in that written scope. It does not include prompts, editable layers, or source files unless explicitly listed.
- Each final delivery is reviewed against the approved brief at its agreed output size.

Portfolio images are web previews. They show visual direction and are not a claim about the resolution of a future commissioned delivery.

The site does not claim native 16K or 24K as a standard capability, professional video editing, certified architectural rendering, real product photography, fabricated clients, fabricated testimonials, guaranteed turnaround, or guaranteed conversion rates.

## Design

The site uses a dark editorial style with warm neutral accents, large artwork, restrained motion, responsive layouts, and a consistent navigation and footer system. The versioned brand pack lives in Vexnaire_Brand_Pack_v1.1 and is tracked with the project.

## Inquiry model and privacy

The website is static HTML, CSS, and JavaScript. When a visitor checks the consent box and submits the project-brief form, the browser sends the supplied name, email, project details, and brief to FormSubmit, which forwards the inquiry to Vexnaire. If that request fails, the site offers a mailto fallback that the visitor can choose to send through their own email provider.

The form does not submit without affirmative consent. The Privacy page explains the data collected, FormSubmit's role, retention, and how to request access or deletion.

## Commercial policy

Every commission receives a written scope before production. It records the final delivery resolution, formats, crop ratios, commercial-use rights, revision count, price, and target date. A Signature Key Visual is generally planned for 5–7 business days and a Three-Visual Campaign Set for approximately 7–12 business days after the scope is confirmed. These are planning estimates, not guaranteed delivery dates.
